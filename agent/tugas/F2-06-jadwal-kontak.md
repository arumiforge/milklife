# F2-06 Pengaturan jadwal dan kontak

| | |
|---|---|
| Status | dikerjakan |
| Tahap | 2 — Pengaturan |
| Dibuat | 11 November 2026 |

## Tujuan

Admin bisa mengelola jadwal (sosialisasi, technical meeting, dan lainnya) serta narahubung dan media sosial.

## Hasil

- [ ] Jadwal: daftar, tambah, ubah, hapus; judul, keterangan, waktu (boleh kosong), tempat, tautan (alamat web yang sah), urutan, tampil
- [ ] Kontak (tabel `tautan`): daftar terpisah untuk narahubung dan media sosial; narahubung berisi label dan nomor WA (dibakukan `NomorWa`), media sosial berisi label dan alamat web; urutan
- [ ] `JadwalModel`, `TautanModel`, uji fitur dan uji basis data

## Selesai bila

`composer uji` lulus; jadwal dan kontak bisa dikelola dari ponsel dan layar lebar.
