# G9-04 Keadaan kosong, galat, dan berhasil

| | |
|---|---|
| Tahap | 9 — Rombak tampilan (K140) |
| Dibuat | 21 November 2026 |
| Dipakai oleh | F9-17 (keadaan kosong, halaman galat), F9-05 (berhasil mendaftar) |

## Tujuan

Layar tanpa data atau layar galat tetap ramah dan memberi tahu pengguna bahwa tidak ada yang rusak.

## Keluaran

Folder `public/aset/gambar/keadaan/`, **WebP alfa 800 × 600, paling besar 100 KB** per berkas, objek di tengah dengan ruang kosong di sekelilingnya.

| Berkas | Adegan |
|---|---|
| `kosong-data.webp` | Kotak kardus terbuka kosong dengan kerucut lalu lintas kecil |
| `kosong-hasil.webp` | Podium juara kosong dengan stopwatch menunggu (jarum, tanpa angka) |
| `tidak-ketemu.webp` | Kaca pembesar di atas lintasan kosong |
| `galat-404.webp` | Anak berlari keluar jalur lintasan, bingung tapi tersenyum |
| `galat-500.webp` | Gawang mini terjatuh dengan kunci pas, anak memperbaikinya |
| `pendaftaran-tutup.webp` | Pintu gerbang stadion tertutup dengan gembok, langit sore |
| `berhasil.webp` | Anak melompat gembira dengan konfeti biru-oranye-magenta |
| `memuat.webp` | Sepatu lari di garis start (dipakai sebagai cadangan saat memuat lama) |

## Selesai bila

Delapan berkas sesuai tabel dan `desain/catatan/G9-04.md` ada.
